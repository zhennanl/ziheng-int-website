# Listing kit: links for BrokerForum, LinkedIn, WeChat and email

`listing-kit.csv` (open it in Excel or Google Sheets) has one row per part with ready-to-paste links.
It is regenerated automatically whenever the inventory changes.

| Column | Use it for |
|---|---|
| BrokerForum link | the "website" or notes field of a BrokerForum (TBF) listing |
| LinkedIn link | LinkedIn posts and company page updates |
| WeChat link (Chinese page) | WeChat chats and Moments: opens the Chinese version of the part page |
| WhatsApp link | WhatsApp chats and status |
| Email link | quote emails, newsletters, email signatures |
| Short text | a one-line description to paste above the link |

Each link carries a tag such as `?utm_source=linkedin`. It does not change the page; it tells your analytics
which platform the visitor came from. In Google Analytics: Reports > Acquisition > Traffic acquisition,
set the dimension to "Session source". (Cloudflare Web Analytics shows the referring site instead.)

When a link is pasted into LinkedIn, WeChat, WhatsApp or email, a preview card appears with the part number,
manufacturer, "In stock" and the part photo. LinkedIn caches previews: to refresh one after a change, paste the
link into https://www.linkedin.com/post-inspector/
